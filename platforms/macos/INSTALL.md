# MLAFMT for macOS / 安装说明

Requires macOS 14 or later. Choose **arm64** for an Apple M-series Mac, or
**x64** for an Intel Mac. The app works offline and does not require Python.

1. Open the `.dmg` and drag **MLAFMT.app** to **Applications**.
2. Open **MLAFMT** from Applications.
3. Choose a draft, fill in your name and title, then save the formatted `.docx`.

The public build is **ad-hoc signed and not Apple-notarized**. On first launch,
macOS may block it. After checking that you downloaded it from the project's
GitHub Releases, use **System Settings → Privacy & Security → Open Anyway**.
macOS may require an administrator's confirmation. Do not disable Gatekeeper.
